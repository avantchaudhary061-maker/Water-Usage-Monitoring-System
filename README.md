# Water Usage Monitoring and Management System

## Introduction
The Water Usage Monitoring and Management System is a DSA-based project developed using C language. It is designed to monitor, record, and manage water consumption efficiently.

## Objectives
- Monitor water consumption records.
- Add, update, search, and delete water usage records.
- Calculate total water consumption.
- Identify the highest water consumer.
- Sort records according to water usage.
- Store records using file handling.
- Promote efficient water management and water conservation.

## Technologies Used
- C Programming Language
- Data Structures and Algorithms
- Linked List
- Linear Search
- Bubble Sort
- File Handling
- Dynamic Memory Allocation

## DSA Concepts Used

### Linked List
Linked List is used to store water usage records dynamically.

### Linear Search
Linear Search is used to find a particular user record using User ID.

### Bubble Sort
Bubble Sort is used to arrange records according to water consumption.

### Traversal
Linked List traversal is used to display and process all records.

### Dynamic Memory Allocation
malloc() and free() are used for dynamic memory management.

### File Handling
File handling is used to save water usage records permanently.

## Main Features
1. Add Water Usage Record
2. Display All Records
3. Search Record
4. Update Record
5. Delete Record
6. Sort Records by Water Usage
7. Calculate Total Water Usage
8. Find Highest Water Consumer
9. Save Records to File
10. Exit

## Project Outcome
The system provides a simple and efficient way to monitor water consumption and manage usage records. It demonstrates the practical application of Data Structures and Algorithms in a real-world problem.

## Conclusion
The Water Usage Monitoring and Management System helps users maintain water consumption records and analyze usage. The project also demonstrates how DSA concepts can be applied to develop an efficient management system.
